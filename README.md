# ttd-updater

[TTD (Torchlight Tracker Diablo)](https://ttdiablo.com) — *Torchlight: Infinite* 팬메이드 동행 도구인
TTD의 업데이트 확인/적용 유틸리티입니다. 구글드라이브에 새 버전이 올라와 있는지 확인하고, 있으면
자동으로 내려받아 적용해줍니다.

이 도구는 TTD 앱 자체를 만들거나 배포하지 않습니다. TTD 본체는 별도로 관리/배포되고 있고, 이 유틸리티는
그 구글드라이브 폴더를 확인해서 "새 zip 받아서 내 설치 폴더에 덮어쓰기"를 자동화해주는 역할만 합니다.

## 사용법

[Releases](https://github.com/listil/ttd-updater/releases)에서 최신 `ttd_updater.exe`를 받은 뒤,
아래 둘 중 하나의 방법으로 실행합니다. **exe 파일을 실행한 그 폴더**가 설치/설치될 위치로 쓰입니다.

1. **기존에 TTD를 설치해둔 폴더에 두고 실행** — 이미 TTD 실행 파일(`TTD.exe`, 또는 아직 예전 방식대로
   `TTD3.4.1.exe`처럼 버전이 붙은 이름일 수도 있음)이 있는 폴더에 `ttd_updater.exe`를 넣고 그 자리에서
   실행하면, 기존 설치를 최신 버전으로 갱신합니다.
2. **새 폴더를 만들고 그 안에서 실행** — 완전히 새로 설치하고 싶다면 빈 폴더를 하나 만들고 그 안에
   `ttd_updater.exe`를 넣어 실행합니다. TTD를 처음부터 새로 받아 그 폴더에 설치합니다.

> 위 두 경우가 아니라면(예: 이미 다른 파일들이 들어있는 폴더, TTD와 무관한 파일이 섞여 있는 폴더)
> 안전을 위해 실행이 자동으로 중단됩니다 — 엉뚱한 폴더에 TTD 파일들이 잘못 풀리는 걸 막기 위해서입니다.

창이 뜨자마자(버전 확인이 끝나기 전에도) 아래 옵션들을 미리 켜둘 수 있습니다. "완료" 버튼은 확인이
끝나야 눌립니다.
- 새 버전이 있으면 자동으로 다운로드/적용됩니다.
- 이미 최신 버전이면 5초 뒤 창이 저절로 닫힙니다(체크박스를 만지거나 버튼에 마우스를 올리면 취소됨).
- 다운로드 도중 창을 강제로 닫거나 꺼도 괜찮습니다 — 받다 만 파일은 임시 폴더에만 있고, 다음 실행 시
  자동으로 정리된 뒤 처음부터 다시 받습니다. 이미 있던 TTD 설치 폴더에는 다운로드가 끝나고 실제로
  적용하는 단계 전까지 아무 파일도 손대지 않습니다.

### 완료 화면 옵션

- **종료 시 아래에서 선택한 항목 실행**: 체크해두면 창이 닫힐 때 아래서 고른 걸 바로 실행합니다.
  - **TTD**: `TTD.exe` 실행
  - **토치라이트**: 게임을 바로 실행. "실행 방식 설정"에서 Steam(App ID) 또는 공식 클라이언트(설치 경로)
    중 하나를 골라 저장해두면 됩니다.
- **바탕화면에 TTD 바로가기 만들기**: 체크하면 바탕화면에 TTD 바로가기(`TTD.lnk`)를 만들어줍니다.
  실행 파일 이름이 항상 고정돼 있어서, 나중에 또 업데이트해도 이 바로가기를 다시 만들 필요 없이 계속
  최신 버전을 가리킵니다.
- **ttd_updater 새 버전 설치**: `ttd_updater.exe` 자신의 새 버전이 있을 때만 나타납니다. 체크하면
  창이 닫힐 때 새 버전을 받아서, 지금 실행 중인 exe를 새 버전으로 바꿔치기합니다(다음에 실행할 때부터
  적용됨 — 지금 실행 중인 창이 새 버전으로 바뀌어 다시 뜨거나 하지는 않습니다).

체크박스 상태는 한 번 정해두면 다음 실행 때도 그대로 기억됩니다(최초 실행 시에는 모두 꺼져 있음;
"ttd_updater 새 버전 설치"만 예외로, 매번 새로 나타날 때마다 다시 선택해야 합니다).

창 제목에 지금 실행 중인 `ttd_updater` 자신의 버전이 항상 표시됩니다.

## 문제가 있다면

- "이 폴더에 TTD와 관련 없어 보이는 파일이 있습니다" 메시지가 뜬다면, 위 사용법의 두 경우(기존 TTD
  폴더 / 새 빈 폴더) 중 하나에 해당하는 위치에서 실행 중인지 확인해주세요.
- 그 외 문제는 [Issues](https://github.com/listil/ttd-updater/issues)에 남겨주세요.
